# 9Innings-5-Tool-Calculator

Lineup and 5-tool (5T) calculator for MLB 9 Innings.

- **Normal Lineup** tab: build one card at a time, compare against a saved build.
- **5T Calculator** tab: max theoretical LST, target-LST solver, train difficulty, Level 8 skill points. Supreme cards can toggle max level 30 (87 dev pts) or 35 (102 dev pts).
- Saved builds are stored in your own browser (localStorage). Use **Export JSON / Import JSON** on the Normal Lineup tab to back them up or move them between devices.

Single static file: `index.html`. No build step, no server.
